Questions teachers actually ask

Do students need accounts or email addresses?

No. A student joins with a room code and a first name. Nothing else about them is stored — no email, no password, no surname, no device identifiers. Hand-ins auto-delete after 60 days.

How is this different from Tinkercad?

Tinkercad is a genuinely good, free CAD tool, and if your students are happily using it you don't need this. CraftPrint trades precision for two things: kids need no login and no lesson on how to use it, and you get the whole class's models as printable files in one click instead of collecting them by hand.

What printer do I need?

Any of them. Exports are standard watertight STL, already oriented and sitting flat on the bed. If you have a multi-material printer, the 3MF export keeps each block's colour.

Will the prints survive being played with?

That's the intent. Blocks are fused into a single solid rather than merely touching, so models don't snap along the seams — while a fine groove keeps the built-from-bricks look. Very thin necks and towers can still break, as with any print.

Our Wi-Fi is unreliable. Does that break the lesson?

The builder runs entirely offline once the page has loaded once, so building never stops. Only the hand-in needs a connection, and students can hand in whenever it comes back.

Is this an official Minecraft product?

No — CraftPrint is an independent project with no connection to Mojang or Microsoft, and contains none of their code or artwork. It's simply built with controls kids already know from that genre.
