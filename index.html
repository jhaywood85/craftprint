❓ How to play

🚶 Walk inside (first person — like Minecraft)

  • 🕹️ WASD or arrow keys to walk, mouse to look
  • 🖱️ Right-click place a block • Left-click break a block (like Minecraft) • Middle-click copy a block
  • ⬆️ Space jump • tap Space twice to fly (Space up, Shift down)
  • 🎨 Scroll wheel or number keys 1–9, 0 pick a color • F paints the block you're looking at
  • 🔺 Z / X / C pick Cube / Wedge / Round (Q cycles them) • R turns the block • T tips it over • G cycles Full → Half → Quarter size
  • ⌨️ Every button shows its key on a little badge — colors are 1–9, 0
  • 🔓 Esc frees the mouse to use the buttons; click the world to dive back in

🎥 Camera view (spin around from outside)

  • 🧱 Pick Build / Erase / Paint, then click the ground or a block
  • 🔄 Drag to spin, scroll to zoom, right-drag to slide • quick right-click erases

🔺 Shapes & sizes (both views)

  • 🧱 Cube, 🔺 Wedge (45° sloped edge), or Round (a quarter circle — smooth roofs lying down, rounded tower corners tipped upright) — pick from the shape bar or press Q to cycle
  • 🔄 Turn (or R) spins a shape around like a top; 🔃 Tip (or T) rolls it over — together they reach every one of the 24 ways a block can face. Watch the ghost preview: it always shows the exact pose you'll place
  • 🔍 The Size button (or G) cycles Full → Half → Quarter for the next block — mix sizes to add fine details to big builds. Half blocks snap to a half grid, quarter blocks to a quarter grid. The button lights up when you're building small.

✨ Everywhere

  • 🦋 Mirror (M): build both sides at once — wedges flip to mirror too, great for roofs and ships!
  • ↩️ Ctrl+Z undo, Ctrl+Shift+Z redo • 📦 My Stuff saves your builds
  • 💾 In My Stuff, ⬇️ Design file downloads your build as a file you can keep, share with friends, or move to another device — ⬆️ Open design file loads it back in, ready to edit (unlike the printed STL, a design file keeps all the blocks)
  • 🏫 Class (top bar): students scan the teacher's QR code with the tablet camera (or type the room code) plus their first name, build, then 🖐 Hand in — the teacher collects every design on one screen and downloads them all, ready to 3D print. No accounts or passwords, just first names.

👨‍🔧 For grown-ups: printing tips

  • “Print It!” downloads a watertight binary STL, already rotated Z-up and sitting on the bed — drop it straight into your slicer.
  • ✨ Soft edges adds a tiny (0.3 mm) bevel along every exposed block edge — corners print less sharp, and block seams show as fine grooves so the model keeps its built-from-bricks look. The grooves are cosmetic only: touching blocks overlap internally by 0.3 mm so the slicer fuses them into one strong solid. Turn it off for perfectly flat, seamless surfaces.
  • The size chips set the edge length of one block (3 / 5 / 8 mm). The dialog shows the final printed size in cm.
  • Floating blocks (not connected to the ground) print as separate loose pieces — the export dialog warns about them and can highlight them.
  • Big overhangs may need supports in your slicer, just like any print.
  • Colors are for fun on screen — the STL is a single solid. Pause-at-height still works great for layered color!
  • Everything is saved in this browser automatically (plus 📦 My Stuff for keepers). No internet needed.
  • 🏫 Class mode needs a one-time free server setup (5 minutes) — see server/README.md in the CraftPrint project, then paste the server address under 🏫 → “For teachers & grown-ups”.
